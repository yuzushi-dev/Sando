# Sando 0.8.3 — One-time consent hooks

- Ask the telemetry question once, at the first `SessionStart`, then switch the `SessionStart` and `UserPromptSubmit` hooks off. Each leaves a marker next to `telemetry.json`, and a shell gate in `hooks.json` answers `{}` without starting `node`, so later sessions and prompts no longer pay for a Node process. No Claude or Codex configuration is written.
- Accept `sando telemetry yes` / `sando telemetry no` only in the session that asked. The first prompt of a later session closes the question; telemetry stays off and can still be enabled with `telemetry-cli.mjs enable`. Installs that were already asked switch both hooks off at their next session start.
- Because the two hook commands changed, Codex asks once to review `session_start` and `user_prompt_submit` in `/hooks` after the update. The tool hooks that feed metrics and accounting are unchanged.
