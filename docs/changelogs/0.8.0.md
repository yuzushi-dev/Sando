# Sando 0.8.0 — Codex and OpenAI compatibility

- Bound external MCP results on Codex with disclosure and hash-verified artifact recovery. Preserve structured content, error state, and tool semantics while bounding model-visible text.
- Add Codex compatibility checks for the stock client and a synthetic loopback provider. The authenticated subscription probe remains separate from offline checks.
- Include the 0.7.1 provider-accounting and artifact-safety updates, plus versioned GPT-6.1 Sol and GPT-6 Luna Standard API price profiles.
- Pilot `gpt-6-luna` at high reasoning through the ChatGPT subscription on an isolated local Codex prototype: 12 attempts produced 12 correct observed answers; 11 runs passed every persisted gate, and five complete pairs averaged 3,629.8 fewer input tokens (13.85%). The six treatment runs reduced transformed text by 74.35% on average.

## Evidence boundary

One control attempt is incomplete because its original process exit status, timeout/overflow state, and hook gate were not retained. It is excluded from paired comparisons and was not retried. These figures are a small descriptive pilot, not a general savings claim; measured runner time includes local setup and is not provider-only latency. Subscription quota was consumed; no API-billed request was made.

The Codex model-output transform was verified on a local prototype. Stock Codex 0.160.0 does not provide that host capability; this release does not claim otherwise.
