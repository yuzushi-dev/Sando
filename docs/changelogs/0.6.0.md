# Changelog: 0.6.0

## 0.6.0

- Adds an optional TypeSafe/Jev shadow judge for bounded, redacted historical-result samples. It is enabled only with `SANDO_TYPESAFE_SHADOW=1`, fails open, and is disabled when the optional package or key is unavailable.
- Adds a provider-neutral offline semantic gate covering Anthropic Messages, OpenAI Chat Completions, and OpenAI Responses. It can restore a deterministic preview only when an injected judge marks likely semantic loss above the configured threshold.
- Adds redaction, request bounds, timeout, cache, and request-budget protections around shadow judging. Cached judge results are whitelisted and carry no request or text payloads.
- Keeps the live proxy measurement-only: the shadow judge never changes the forwarded request, and the offline gate is not wired into live traffic.
- Adds provider-free semantic-quality tests for loss, preservation, fail-open behavior, and threshold handling. These tests validate gate mechanics, not TypeSafe model accuracy.

No new provider-savings claim is made. Existing reduction benchmarks and the deterministic live path remain unchanged.
