# Sando 0.8.2 — Leaner Codex shell results

- Write `stdout:`/`stderr:` headers in routed Codex shell results only when stderr has content. A command with output on stdout alone now returns the status line followed by its output, and a silent command returns only the status line, so Codex cells no longer end with an empty `stderr:` section.
- Keep both headers when bare stdout would itself begin with `stdout:`, so the two layouts stay unambiguous; the Codex compatibility verifier parses both and reports the same exit-code and stream fidelity as 0.8.1.
