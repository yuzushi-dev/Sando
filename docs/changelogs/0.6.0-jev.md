# Changelog: 0.6.0-jev

## 0.6.0-jev (Parallel Edition)

- **TypeSafe Jev Integration**: Adds intelligent semantic guards powered by TypeSafe AI (System One model `jev-latest`) alongside Sando's high-speed deterministic token compression.
- **DoneGuard (Anti-Deception)**: Anchored to session telemetry (`testsPassedAfterLastEdit`). Intercepts premature or unverified completion claims when code files were modified without a passing test suite run.
- **StuckGuard (Loop Prevention)**: Two-tier architecture:
  - Tier 1: Zero-latency, zero-cost local deterministic check for identical command failures.
  - Tier 2: Semantic Jev evaluation for syntactic drift and varying failure loops.
- **Strict Fail-Open Guarantee**: Guards operate with bounded timeouts (1500ms + 200ms hard ceiling with unref) and an offline deterministic heuristic fallback. Host execution never crashes or hangs if the network or API key is unavailable.
- **Privacy & Security First (Option B)**: Zero plaintext credentials in repos or transcripts. Supports standard XDG storage in `~/.config/typesafe/auth.json` (mode 0600) with automatic bidirectional scrubbing of tokens and secrets.
