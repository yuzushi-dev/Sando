# Sando 0.8.4 — eMudhra CA security update

- Require Node.js `>=22.23.4 <23`; this exact release rejects both published eMudhra certificate-chain canaries with `CERT_REVOKED`.
- Pin CI and npm publishing to Node.js `22.23.4` so tests, packaging, and publication do not run on the tested affected `22.22.0` or `22.22.1` runtimes.
- Keep Sando's TLS behavior on Node's standard verifier; no private CA bundle or application-specific certificate override is introduced.
