# Sando 0.7.1

- Disclose redaction in bounded tool output and artifact views without changing retained artifact content.
- Improve Codex compatibility, output byte budgeting and executable bounded artifact recovery hints.
- Add validated provider usage accounting and immutable Sol/Luna Standard API pricing profiles.
- Correct artifact retrieval counting for absolute and quoted commands, with strict native benchmark provenance and evidence validation.
- Preserve the opt-in adoption telemetry introduced in 0.7.0.
- Bounds external MCP results on Claude. The `PostToolUse` hook now caps each `text` block of an `mcp__*` result with the same optimizer and caps as other tool output and returns it through `updatedMCPToolOutput`. Non-text blocks and responses that are not a content array pass through untouched, and Sando's own MCP tools are never bounded. When the bounded blocks still add up to more than 16 KiB they are merged into one bounded view with one artifact. Earlier versions left these results unchanged.
- Recovers hook-written artifacts through `sando_artifact_get`. When the handle is not in the MCP process, the tool reads `.sando/sando/artifacts/<sha256>.txt` under the project directory. It accepts a hex prefix of at least 16 characters, requires exactly one matching file, opens it without following symlinks, and verifies the full SHA-256 before returning content. The in-process store takes precedence, the existing `maxBytes` and range limits apply, content and digest cannot be supplied by the caller, and unknown arguments are rejected. On Claude the recover hint in a bounded result names `sando_artifact_get` instead of the `sando artifact get` CLI, which is not on the model's PATH there. Codex hints are unchanged.
- Moves the Claude status line to `$.ui.status` through a thin hooks module on Claude Code 2.1.287 and later. The module only displays the output of `statusline.mjs`, refreshes without delaying any result, and never changes one; `statusline.mjs` stays as the fallback for older versions. The module cannot see the session cost, so the cost segment of the status line may be missing there. The `modules` key in `hooks.json` was checked to be harmless on Claude Code 2.0.70, 2.1.0 and 2.1.261.
- Makes the Claude hook fail closed. A result sized for its source class but above the 4 KiB default no longer makes the hook throw an output-budget error (the hook now finalizes against the budget the optimizer used). On any internal error in apply mode it emits a redacted, hard-truncated copy, or a "[sando] output withheld" placeholder, and exits 0. Exit code 2 on `PostToolUse` was checked on 2.1.287 and leaves the original result visible to the model next to the stderr text.
- Writes Claude artifacts under `CLAUDE_PROJECT_DIR` when it is set, so recovery still finds them after the session changes directory; the printed path is absolute in that case.
- Fixes the recover range so it no longer counts the `[sando] artifact` header line as source text: `startLine` includes the partially visible head line, which was previously unrecoverable.
- Redacts extra structured fields with `redactStructured` and appends the display-redaction notice once. The Claude hook entrypoint now re-exports the canonical `hook-cli.mjs`, copied into the Claude bundle by `sync:bundles`, instead of keeping a diverging copy. As a result the Claude hook runs the same code path as the canonical hook, including the consent-gated adoption recording that was already part of it; adoption stays off unless enabled.

### Codex

These come from the shared core and change Codex output as well. They are kept on purpose as security hardening and are asserted in `packages/sando/tests/core-hardening.test.mjs` and the Codex adapter tests.

- A result with redactions ends with one `[sando] display redacted; Sando did not sanitize source files` line, counted inside the inline budget: with a 1024-byte cap the redacted result is 1023 bytes including it.
- Redaction runs a second time on the VT-stripped preview for every tool. Before, the second pass and the stripping applied only to Bash, so a secret split by an ANSI sequence in Read or Grep output was returned unredacted (checked against the 0.6.1 core).
- When the exec status line cannot fit the inline budget, the view starts with `[exit_code=N]` instead of a truncated `[sando exec ...` line.

One live `claude -p` check on 2.1.287 with a stdio MCP server returning 19 KB: the result was bounded with a `sando_artifact_get` hint and lines were recovered through that tool, also after a `cd` into a subdirectory. This is a functional check, not a measurement; the Claude reduction figures in `docs/measurements.md` predate this change and still exclude MCP results.

Ten paired GPT-6 Luna sessions passed all task checks on a full-inspection log task. Sando used 170 tool calls versus 157 without Sando. Hypothetical Standard API cost decreased 0.19%, below the predeclared 10% target; this does not establish subscription savings. Native evidence and account receipts remain private.
