# Changelog: 0.4.3

## 0.4.3

- Makes Codex CLI routing and provider-request transformation explicit opt-ins. Action is required to enable either path: set `SANDO_CLI_ROUTING=1` for transparent CLI routing and `SANDO_PROXY_TRANSFORM=1` for provider-request transformation; both remain off by default.
- Keeps opaque OpenAI tool results lossless unless explicit success evidence is present; ambiguous or missing evidence fails closed and leaves the result unchanged.
- Corrects Claude emitted-payload metrics and provider cache attribution.
- Adds independent historical-transform switches and bounded artifact cleanup.
- Retains only the validated M0 safety and tool-output projection work; experimental M1–M5 lifecycle code is not included.

### Evidence boundary

- The exploratory benchmark recorded the 0.4.3 release candidate as quality-equivalent to `main`, but did not demonstrate an improvement over `main` (`n=5`, `p=.375`). This is not an economic or provider-savings claim.
- That run did not cover the provider proxy, so it provides no proxy quality or savings conclusion.
